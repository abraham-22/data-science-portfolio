
# 📈 Cryptocurrency Market Analysis

## 🧠 Project Overview

This project applies unsupervised machine learning techniques to explore the cryptocurrency market. The primary goal is to identify which cryptocurrencies are currently being traded and to classify them based on their attributes, ultimately establishing a system for understanding this emerging class of digital assets.

---

## 🎯 Purpose

The analysis focuses on:

- Identifying active cryptocurrencies in the market
- Exploring their characteristics and key metrics
- Grouping cryptocurrencies using clustering algorithms to build a classification system
- Enhancing investment insights for potential investors or analysts

## 📊 Methodology

1. **Data Collection & Cleaning**  
   Load and preprocess the dataset to ensure consistency and remove missing values.

2. **Exploratory Data Analysis (EDA)**  
   Visualize key distributions, trends, and relationships in the cryptocurrency market.

3. **Feature Engineering**  
   Prepare relevant features for clustering by scaling and transforming as needed.

4. **Clustering with K-Means**  
   Apply unsupervised learning to group cryptocurrencies into clusters.

5. **Dimensionality Reduction with PCA**  
   Reduce the feature space for better visualization and interpretation of clusters.
